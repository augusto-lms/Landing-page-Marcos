Landing Page | Marcos Camargo Garcia
Landing page desenvolvida para apresentar o trabalho de Marcos Camargo Garcia, representante comercial de moda com foco em jeanswear, atendimento consultivo e relacionamento com lojistas de Minas Gerais.

O projeto foi pensado para unir presença digital, clareza comercial e geração de contato, com destaque para marcas representadas, catálogo das coleções e conversão direta via WhatsApp.

Objetivo do projeto
Mais do que uma vitrine, esta landing page foi construída para funcionar como um ponto de contato comercial: transmitir confiança, reforçar autoridade no segmento e facilitar o primeiro passo de novos clientes.
